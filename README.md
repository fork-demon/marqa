# Marqa

### A minimal, designer-friendly markdown editor.

Write in rich text or markdown. Draw diagrams. Manage multiple files. Present your work. Nothing more.

[marqa.tech](https://marqa.tech/)

---

## ✨ Features

- **🔄 Rich Text + Source**: Switch between a clean rich text editor and raw markdown with a single click.
- **📊 Diagrams**: Draw flowcharts and shapes on a built-in canvas, or write Mermaid code directly to visualize your ideas.
- **🗂️ Tabs + Workspaces**: Open multiple files in tabs and work across several folders simultaneously.
- **📺 Presentation Mode**: Turn any document into a full-screen presentation instantly—no export required.
- **⚡ Native Performance**: Built with **Tauri** and **SvelteKit** for a lightweight, secure, and blazingly fast desktop experience.
- **🎨 Minimalist UI**: A distraction-free interface designed to help you focus on your writing.

## 🛠️ Installation

### Download
You can download the latest version for macOS and Windows from the [Releases page](https://github.com/fork-demon/marqa/releases).

### macOS Note
If you see the "App is damaged" message on the first launch, run this command in your Terminal:
```bash
xattr -cr /Applications/Marqa.app
```
*This is a one-time security step required for unsigned open-source apps.*

## 🚀 Development Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (latest LTS)
- [Rust](https://www.rust-lang.org/tools/install)
- [Tauri dependencies](https://tauri.app/v1/guides/getting-started/prerequisites)

### Steps
1. **Clone & Install**
   ```bash
   git clone https://github.com/fork-demon/marqa.git
   cd marqa
   npm install
   ```
2. **Run Dev Server**
   ```bash
   npm run tauri dev
   ```
3. **Build Binary**
   ```bash
   npm run tauri build
   ```
